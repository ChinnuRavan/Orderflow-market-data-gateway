
# Orderflow Market Data Gateway

A Spring Boot + WebFlux application that acts as a Market Data Gateway for processing and streaming market data.

## Technologies Used
- Java 21
- Spring Boot 4
- Spring WebFlux
- Maven
- Git & GitHub

## Features
- REST API
- Reactive Programming (Mono & Flux)
- Market Data Processing
- WebSocket Support (Coming Soon)

## Project Structure
src
 ├── controller
 ├── service
 ├── model
 ├── config
